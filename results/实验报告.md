# SkillLearnBench Qwen 基线复现实验

正式评估覆盖 23 个实例的 69 组组合。每组执行一次。四类任务为地震板块计算、金融分析、加权 GDP 和股票可视化。

使用百炼北京区 qwen3.5-plus。温度 0，关闭思考，每次输出最多 2048 token，每组最多 100 步。实验使用 Windows、Docker Linux 容器和固定的 SkillLearnBench 上游版本。求解保留最近三轮交互，历史较早部分保留摘录。

## 与人工 Skill 的差距

- none 通过率 0.00%，人工 Skill 通过率 43.48%，差值 -43.48 个百分点。该组较常见的失败证据为 max_turns、地震距离口径或数值、金融答案内容。
- b1-one-shot 通过率 4.35%，人工 Skill 通过率 43.48%，差值 -39.13 个百分点。该组较常见的失败证据为 max_turns、金融答案内容、地震距离口径或数值。

人工 Skill 提供可复用的任务步骤和边界条件。地震距离口径、金融数据匹配以及表格与图表的输出约束需要分别核对。自动生成的 Skill 来自单个生成实例，其流程可能遗漏变体的具体要求。逐组轨迹和官方检查支持定位差异。一次运行与同模型族自动评分只能提供描述性证据。

## 适配与指标说明

Skill 直接注入模型上下文，论文使用 CLI 自动加载。当前适配器不提供显式 Skill 工具，另报告文件引用代理值。Skill-task Alignment 是附加指标。Trajectory Alignment 为关键点召回与执行顺序、完整性归一化后的均值。长轨迹评分可能使用摘录，完整原轨迹保留。运行期间修订了评分输出字段约束和超长输入处理，可从原始评分请求核查。

正式求解、评分和技能生成的可见 token 总量详见 report.json。费用账本包含未取得使用量时的保留预留、调试和中断尝试。
