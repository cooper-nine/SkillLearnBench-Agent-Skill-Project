# 正式失败案例复盘

下表覆盖失败统计中的主要类型。步号是原始 `agent/qwen.txt` 中的 `assistant.step`。官方检查和差值来自同一运行目录下的 `verifier/ctrf.json`。原因栏把可以由日志确认的事实与仍需验证的推断分开。

| 具体实例 | 官方失败项 | 轨迹证据 | 原因推断 |
|---|---|---|---|
| 地震 1 / none | `test_distance_within_tolerance`。输出 4152.56 km，期望 3878.27 km，容差 0.01 km。 | 第 18 步用 EPSG:3857 投影后计算点到边界的平面距离并写文件，第 19 步读回 4152.56 km。距离是该组唯一失败的官方检查。 | 事件选择已通过，差距出在距离计算。投影与边界选取是优先排查对象。用同一事件、同一边界替换投影做对照，才能确认投影造成多少差值。 |
| 地震 2 / none | `test_earthquake_id_correct` 和 `test_distance_within_tolerance`。实际 ID 为 us6000nhcw，期望 us7000mt2v。实际距离 6556.99 km，期望 0.08 km。 | 第 14 步将 6556.986687 四舍五入，并注释为到 Africa 板块边界的距离。第 15 步读回 ID 与该距离。 | 选错事件和距离口径分别可见。应分开复核用于挑事件的条件、距离参照对象和输出字段，无法从最终 JSON 单独确定第一个出错步骤。 |
| 金融 1 / one-shot | `test_answer_quality`。q2 为 3457，期望 2451。 | 第 14 步调用 `python` 返回 127。第 16 步用 `python3` 成功运行，匹配到 Renaissance 的 Q3 申报记录并打印持仓数 3457，第 17 步读回答案。 | 解释器问题已在该次运行内绕过。剩余差值应核对持仓行数、证券去重和资产筛选口径。日志足以定位到持仓计数，尚未通过逐行对账证实具体多算了哪一类记录。 |
| 金融 2 / none | `test_file_exists`，缺少 `/root/answers.json`。后续答案检查因同一文件缺失而失败。 | 第 98–100 步仍在查 Palantir 持仓及申报机构名称，累计 100 次模型响应，轨迹结束时 `completed=false`。 | 轮次耗尽前未完成答卷写入。两条官方失败项来自同一个缺文件问题。 |
| GDP 1 / none | `test_exports_values`、`test_imports_values`、`test_gdp_values`。例如 J26 期望 GDP 415.2，实际是年份 2021.0。 | 第 7 步查看 Data 表和 Task 表的年份列。第 20 步展示示例公式，三个区块都在 Data 表第 21–40 行用相同区域按 series code 与年份查找。第 21 步检查的是单元格是否有公式。 | 公式存在只验证了结构，未验证重算值。三类指标共用查找区域且 GDP 单元格得到年份，应优先核对指标所在的数据块和返回区域。 |
| 股票 1 / human_authored | `test_output_structure_and_files`。要求的 `/root/output/data/indiv-stock-indiv-stock/` 目录缺失。 | 第 99 步下载 D3 并列出 JS 文件，第 100 步仍在读取源数据验证 ETF 和股票类型。官方目录检查显示数据目录未交付。 | JS 文件已生成，交付目录清单未全部满足。可先用一条文件树检查验证目录，再进入浏览器测试。 |
| 股票 2 / human_authored | `test_data_table` 检出图表和表格的纵向偏移 581 px，要求低于 200 px。提示框与图表表格联动也失败。 | 第 99 步还在查看 ticker、行业和市值字段。第 100 步写入 CSS，其中已有 `.tooltip.visible` 规则，工具输出为 `CSS created`。 | CSS 类存在只能说明样式已写。官方浏览器检查表明实际布局、悬停和联动仍未符合要求。应使用相同页面尺寸复测并查看事件触发和 DOM 状态。 |
